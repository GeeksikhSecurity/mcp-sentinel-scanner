Security Best Practices: MCP Server Hardening

Follow these best practices to secure your MCP server infrastructure and reduce attack surface against supply chain threats.

  • Scan Before Deploy: Always run MCP Sentinel Scanner before deploying MCP servers to production. Integrate into CI/CD for automated gating.
  • Review High ASR Findings: Prioritize vulnerabilities with Attack Success Rate > 0.7. These represent critical risks requiring immediate remediation.
  • Environment Variable Safety: Never hardcode secrets in MCP server code. Use environment variables with restricted access and rotation policies.
  • Input Validation: Sanitize all user inputs and tool parameters before processing. Use allowlists rather than blocklists for validation.
  • Dependency Pinning: Lock all MCP SDK and dependency versions in requirements.txt. Use dependency scanning tools for known CVEs.
  • Least Privilege: MCP servers should run with minimal filesystem and network permissions. Use Docker security contexts and read-only mounts.
  • Regular Scanning: Schedule weekly scans of production MCP servers. Monitor for new vulnerabilities and emerging patterns.
  • SARIF Integration: Upload scan results to GitHub Security/Code Scanning for centralized vulnerability tracking and developer notifications.

  with:
    format: sarif
    fail-on: critical
